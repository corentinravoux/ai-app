# Remote end-to-end, 2026-11-13

Laptop (work) → home PC (corentin-MS-7B86, RTX 3060) over Tailscale + SSH.

Setup: openssh-server on the PC (key-only, no root login,
`/etc/ssh/sshd_config.d/10-ai-app.conf`), Tailscale on both machines, a
dedicated `id_ai_app` key on the laptop, `Host pc` in the laptop's
`~/.ssh/config`. In AI App on the laptop: host *Over SSH*, target `pc`,
llm-host command `/home/corentin/.local/bin/llm-host`.

| check | result |
|---|---|
| `ssh -o BatchMode=yes pc -- /home/corentin/.local/bin/llm-host status` | ok |
| Start Qwen3.6 35B-A3B · 64K from the laptop | ok (loaded on the PC) |
| Probe from the laptop | PASS |
| Pi on the laptop against the PC's model | ok; on the PC, a 6,163-token prompt at ~600 tok/s, generation 30–39 tok/s |
| llama-server bound to 127.0.0.1 only on the PC | yes |
| Wi-Fi off 30 s during a Pi turn | row unreachable within ~15 s, back by itself, same tab works again |
| Model stopped under an open tab, and the other drills | ok ("everything is working fine", user) |

Note: `~` in an `ssh … -- ~/…` command typed on the laptop is expanded by
the laptop's shell; use the absolute path (`/home/corentin/…`), as the
host's llm-host command does.
